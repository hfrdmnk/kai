kai

A UI annotation tool for developers and AI agents.

Click any element on a web page, describe what should change, and export structured feedback as JSON or Markdown. kai runs entirely client-side as a single Web Component — zero dependencies, nothing to install on the server.

Get started

Chrome extension — install locally

Download kai-extension.zip

Unzip it, open chrome://extensions, turn on Developer mode and choose Load unpacked. Click the kai icon in the toolbar to toggle it on any page.

回 kai — Japanese for "turn," as in a turn in a cycle. Annotate what needs to change, hand it to your coding agent, and move on to the next iteration. Fewer rounds, tighter loops.
